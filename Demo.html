airflow — pipeline_health_monitor DAG
Apache Airflow 2.x · Python · AWS S3 · boto3 · XCom
Hourly DAG · SLA validation · on-call runbook
What this shows: An Airflow DAG that validates S3 file arrival SLAs and row count thresholds every hour. Raises exceptions on failure, triggering alerts before downstream systems are affected. Includes a production on-call runbook for incident response.
kafka_ops.py — MSK consumer lag monitor
AWS MSK · kafka-python · CloudWatch · Python · offset management
Producer · consumer · lag monitoring · CloudWatch publish
What this shows: Producer and consumer scripts for AWS MSK with per-partition lag calculation. Publishes lag as CloudWatch custom metrics. Uses manual offset commits so messages aren't lost if the consumer crashes mid-processing.
terraform — AWS DataOps landing zone
Terraform · AWS S3 · IAM · Lambda · SNS · Snowflake integration
7 resources · remote state · Snowflake IAM trust
What this shows: Infrastructure as Code for a full DataOps environment — S3 with lifecycle policies, IAM roles for Snowflake storage integration using sts:ExternalId, Lambda pipeline trigger, and SNS alerting. Everything version-controlled and repeatable across environments.
docker compose — Prometheus + Grafana stack
Prometheus · Grafana · Docker Compose · PromQL · Python ETL · SQLite
LIVE — running right now
What this shows: A fully working end-to-end observability pipeline. Python generates sales data → ETL loads into SQLite → metrics exporter serves PromQL → Prometheus scrapes every 15s → Grafana live dashboard at localhost:3001. This one is actually running on this machine right now.
